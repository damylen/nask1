# KrachtQuest

Korte oefenapp voor vmbo-kgt/mavo NaSk1.

Onderwerp: krachten en beweging.

De app heeft 7 stappen met:

- korte vragen
- hints bij fouten
- simpele uitleg
- visualisaties

Live versie: [https://damylen.github.io/nask1/](https://damylen.github.io/nask1/)

## Ontwikkelen

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
